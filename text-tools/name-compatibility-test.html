How name compatibility is calculated

This tool uses multiple methods to score compatibility: letter frequency analysis, numerology (assigning values A=1 to Z=26), the classic FLAMES game, and a compatibility algorithm that weighs shared sounds, vowel patterns, and name length harmony.

🔥 FLAMES Method

Count total unique letters in both names, then cycle through F-L-A-M-E-S, eliminating one letter at each count. The surviving letter determines your relationship: Friends, Love, Affection, Marriage, Enemies, or Siblings.

🔢 Numerology

Each letter is assigned a value (A=1, B=2… Z=26). Summing name values and reducing to a single digit gives a Life Path Number. Compatible numbers create harmony; certain pairs have natural synergy.

🔤 Letter Matching

Shared letters between names indicate common energy and resonance. Names sharing more than 40% of letters tend to have natural compatibility in numerological traditions.

⚠️ For fun!

This is an entertainment tool inspired by popular name compatibility games. Real relationships are built on respect, communication, and shared values — not just name letters!

Frequently asked questions

How is the compatibility percentage calculated?
The percentage combines four factors: letter overlap score (30%), numerology harmony (25%), FLAMES result value (25%), and name pattern compatibility (20%). The result is weighted and displayed as a 0-100% score.
What is the FLAMES test?
FLAMES is a classic pen-and-paper game. Write both names, cross out common letters, count remaining letters, then cycle through F-L-A-M-E-S, crossing off one letter at each count interval. The last remaining letter reveals your relationship type: Friends, Love, Affection, Marriage, Enemies, or Siblings.
Should I use my full name or nickname?
Try both! Your full name, nickname, and even how they'd write your name can give different results. Many people find their nickname compatibility more interesting. There's no "correct" version — try the name you're most commonly called.
Is this scientifically accurate?
This is purely for entertainment. Name compatibility calculators are a fun, viral game inspired by numerology and folk traditions. Real relationship compatibility depends on personality, values, emotional intelligence, and communication — not names. Enjoy it as the fun it is!
Can I test friendship compatibility?
Absolutely! Change the relationship type to "Friendship" before testing. The scoring adjusts to emphasise complementary traits and shared energy rather than romantic compatibility markers.
