Frequently asked questions

How do I make text vertical?
Type your text, choose a vertical style (stacked, top-to-bottom, rotated etc.) and click Copy. The vertical text uses standard text characters and line breaks so it pastes correctly anywhere that supports Unicode.
Where can I use vertical text?
Vertical text works in Instagram bios and captions, Twitter/X posts, Discord, WhatsApp, Facebook, Google Docs, websites, presentations and any platform that supports Unicode and line breaks.
What is the difference between stacked and rotated text?
Stacked text places each character on its own line, reading top to bottom. Rotated text uses Unicode characters that appear physically rotated 90 degrees. Both are visually vertical but look quite different.
Can vertical text be copied and pasted?
Yes — all vertical styles generated here use standard text characters and line breaks. They copy and paste correctly in any app that supports Unicode text, including Instagram, Twitter, WhatsApp and email.
What is the difference between top-to-bottom and bottom-to-top?
Top-to-bottom (↓) places the first letter at the top and reads downward. Bottom-to-top (↑) reverses the order so the first letter is at the bottom — like rotated horizontal text reading upward.
